# NEA-Documentation
Recording the technical solution of my NEA here

Patients would use online form of a hospital to record some of their healhh data and symptoms.
A neural network would use the data to find the most likely symptom and then the system 
would link the patient with the respective doctor. Then an appointment would be recorded
in a back-end SQL database.

Includes separate login and controls for staff members, as well as:
email validation; strong password checking; neural network made using only numpy as import
